# POS-spezifischer Prompt: ADP

## Präpositionen haben IMMER nur EINE meaning

Präpositionen werden NICHT in mehrere meanings aufgeteilt. Alle Verwendungen werden in einer meaning zusammengefasst, mit hints zur Unterscheidung der Kontexte.

---

## Beispiele

### Präposition mit mehreren Verwendungen

```json
{
  "id": "00701",
  "lemma": "por",
  "pos": "ADP",
  "meanings": [
    {
      "definition_es": "preposición con múltiples usos: causa, movimiento, intercambio, agente",
      "structure": "por",
      "flags": [],
      "translations": [
        {"text": "wegen", "hint": "Grund"},
        {"text": "durch", "hint": "Bewegung"},
        {"text": "für", "hint": "Preis/Tausch"},
        {"text": "von", "hint": "Passiv"}
      ]
    }
  ]
}
```

### Einfache Präposition

```json
{
  "id": "00702",

  "pos": "ADP",

    {
      "definition_es": "indica ausencia o carencia de algo",
      "structure": "sin",
      "flags": [],
      "translations": [{"text": "ohne"}]
    }
  ]
}
```
