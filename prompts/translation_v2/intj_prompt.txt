# POS-spezifischer Prompt: INTJ

## Interjektionen haben IMMER nur EINE meaning

Interjektionen werden NICHT in mehrere meanings aufgeteilt.

---

## Beispiele

### Interjektion

```json
{
  "id": "01001",
  "lemma": "oye",
  "pos": "INTJ",
  "meanings": [
    {
      "definition_es": "llamar la atención de alguien de forma informal",
      "structure": "oye",
      "flags": [],
      "translations": [{"text": "hey"}, {"text": "hör mal"}]
    }
  ]
}
```

### Ausruf

```json
{
  "id": "01002",
  "lemma": "ay",
  "pos": "INTJ",
  "meanings": [
    {
      "definition_es": "expresión de dolor, sorpresa o emoción",

    }
  ]
}
```
