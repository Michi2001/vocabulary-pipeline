# POS-spezifischer Prompt: VERB

## Structure-Feld bei Verben

**Reflexive Verben mit Bedeutungsänderung:**
- `encontrar` → "finden" vs. `encontrarse` → "sich treffen"
- `ir` → "gehen" vs. `irse` → "weggehen/abreisen"
- `dormir` → "schlafen" vs. `dormirse` → "einschlafen"

**NICHT als separate meaning wenn Reflexivform nur "sich + Grundform" bedeutet:**
- `vender` → "verkaufen" / `venderse` → "sich verkaufen" (keine separate meaning)
- `lavar` → "waschen" / `lavarse` → "sich waschen" (keine separate meaning)

```json
    {
      "definition_es": "dar con algo o alguien que se buscaba",

      "flags": [],
      "translations": [{"text": "finden"}]
    },
    {
      "definition_es": "reunirse con alguien de manera acordada o casual",
      "structure": "encontrarse",
      "flags": [],

    },
    {
      "definition_es": "estar en un lugar o en cierto estado",
      "structure": "encontrarse",

```
