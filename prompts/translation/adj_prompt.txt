# POS-spezifischer Prompt: ADJ (Adjektiv)

## JSON-Struktur für Adjektive

```json
{
  "id": "00XXX",
  "lemma": "bueno",
  "pos": "ADJ",
  "meanings": [
    {
      "structure": "ser bueno",
      "example_es": "Ejemplo en español.",
      "estimated_share": 0.7,
      "flags": [], 
      "translations": [
        {
          "text": "gut"
        }
      ]
    }
  ]
}
```

## Besonderheiten für Adjektive

### Ser vs. Estar (sehr wichtig!)
Viele spanische Adjektive haben **unterschiedliche Bedeutungen** mit ser und estar:
> ser und estar nur dann verwenden, wenn das Wort mit ser und estar unterschiedliche Bedeutung hat

#### Wann ser/estar in structure verwenden:
✅ **JA** - Wenn Bedeutung unterschiedlich:
- `ser listo` = schlau / `estar listo` = fertig
- `ser rico` = reich / `estar rico` = lecker
- `ser malo` = böse / `estar malo` = krank/schlecht

❌ **NEIN** - Wenn Bedeutung gleich:
- `ser/estar feliz` = glücklich (gleiche Bedeutung) → nur `feliz`
- `ser/estar importante` = wichtig → nur `importante`

### Position des Adjektivs
Manche Adjektive ändern die Bedeutung je nach Position:

**Wenn Position wichtig ist:**
- `viejo [sustantivo]` = langjährig (viejo amigo)
- `viejo` (nach Substantiv) = alt (hombre viejo)
- `gran [sustantivo]` = großartig (gran científico)
- `grande` (nach Substantiv) = groß (casa grande)

**Wenn Position nicht wichtig:**
- nur das Adjektiv ohne Platzhalter

### Structure-Feld Beispiele
✅ Richtig:
- `ser listo` / `estar listo` (unterschiedliche Bedeutung)
- `gran [sustantivo]` / `grande` (Positionsunterschied)
- `ser seguro` / `estar seguro` (unterschiedliche Bedeutung)

❌ Falsch:
- `[sustantivo] grande` → nur `grande`
- `bonito [sustantivo]` → nur `bonito` (Position ändert nichts)
