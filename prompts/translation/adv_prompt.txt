# POS-spezifischer Prompt: ADV (Adverb)

## JSON-Struktur für Adverbien

```json
{
  "id": "00XXX",
  "lemma": "bien",
  "pos": "ADV",
  "meanings": [
    {
      "structure": "bien",
      "example_es": "Ejemplo en español.",
      "estimated_share": 0.5,
      "flags": [], 
      "translations": [
        {
          "text": "gut"
        }
      ]
    }
  ]
}
```

## Besonderheiten für Adverbien

### Structure-Feld
Bei Adverbien ist das structure-Feld wichtig, wenn:

#### WICHTIG: Sei sparsam mit Platzhaltern!

✅ **MIT Platzhalter (nur wenn notwendig):**
- `bien [adjetivo]` = sehr/ziemlich (zeigt, dass Adjektiv modifiziert wird, nicht Verb)
- `cerca de [algo]` = in der Nähe von (Präposition gehört zur Struktur)

❌ **OHNE Platzhalter (Standard):**
- `ya` = schon (NICHT `ya [verbo]` - selbstverständlich)
- `ya no` = nicht mehr (NICHT `ya no [verbo]`)
- `bien` = gut (wenn es Verb modifiziert - das ist Standard)
- `cerca` = in der Nähe (ohne Präposition)
- `lejos` = weit
- `aquí` = hier
