# POS-spezifischer Prompt: ADV (Adverb)

## JSON-Struktur für Adverbien

```json
{
  "id": "00XXX",
  "lemma": "bien",
  "pos": "ADV",
  "meanings": [
    {
      "structure": "bien",
      "example_es": "Ejemplo en español.",
      "estimated_share": 0.5,
      "flags": [], 
      "translations": [
        {
          "text": "gut"
        }
      ]
    }
  ]
}
```

## Besonderheiten für Adverbien

### Structure-Feld
Bei Adverbien ist das structure-Feld wichtig, wenn:

#### Position oder Kombination relevant ist:
✅ **MIT Platzhalter:**
- `ya [verbo]` = schon (zeigt Position vor Verb)
- `ya no [verbo]` = nicht mehr (feste Kombination)
- `bien [adjetivo]` = sehr/ziemlich (modifiziert Adjektiv)
- `cerca de [algo]` = in der Nähe von (mit Präposition)

❌ **OHNE Platzhalter:**
- `bien` = gut (wenn es Verb modifiziert - das ist Standard)
- `cerca` = in der Nähe (ohne Präposition)
- `lejos` = weit
- `aquí` = hier

### Typische Adverb-Strukturen

#### 1. Temporale Adverbien
- `ya [verbo]` = schon
- `ya no [verbo]` = nicht mehr
- `todavía` = noch/immer noch
- `aún` = noch/sogar

#### 2. Modale Adverbien
- `bien` = gut
- `mal` = schlecht
- `así` = so

#### 3. Lokale Adverbien
- `cerca` = in der Nähe
- `cerca de [algo]` = in der Nähe von
- `lejos` = weit
- `aquí/ahí/allí` = hier/da/dort

#### 4. Graduale Adverbien
- `muy` = sehr
- `bien [adjetivo]` = sehr/ziemlich/echt
- `bastante` = ziemlich

### Feste Wendungen
Wenn das Adverb in einer festen Wendung vorkommt:
- `estar bien` = gut gehen (Person/Situation)
- Erstelle einen separaten meaning-Eintrag dafür
