# POS-spezifischer Prompt: NOUN (Substantiv)

## JSON-Struktur für Substantive

```json
{
  "id": "00XXX",
  "lemma": "palabra",
  "pos": "NOUN",
  "meanings": [
    {
      "gender": "f",  // oder "m"
      "example_es": "Ejemplo en español.",
      "estimated_share": 0.6,
      "flags": [],
      "translations": [
        {
          "text": "deutsche Übersetzung",
          "gender_target": "f"  // oder "m", "n"
        }
      ]
    }
  ]
}
```

## Besonderheiten für Substantive

### Gender (Geschlecht)
- **Pflichtfeld `gender`**: Gib das spanische Geschlecht an ("f" oder "m")
- **Pflichtfeld `gender_target`**: Gib das deutsche Geschlecht an ("f", "m", oder "n")
- Bei unterschiedlichen Bedeutungen mit unterschiedlichen Geschlechtern: erstelle separate meaning-Einträge

### Beispiel: Wort mit verschiedenen Geschlechtern und Bedeutungen
```json
{
  "lemma": "capital",
  "meanings": [
    {
      "gender": "f",
      "example_es": "Madrid es la capital de España.",
      "estimated_share": 0.5,
      "flags": [],
      "translations": [{"text": "Hauptstadt", "gender_target": "f"}]
    },
    {
      "gender": "m",
      "example_es": "La empresa necesita más capital.",
      "estimated_share": 0.5,
      "flags": [],
      "translations": [{"text": "Kapital", "gender_target": "n"}]
    }
  ]
}
```

### Structure-Feld bei Substantiven
- Normalerweise **kein** structure-Feld nötig
- Nur bei speziellen Konstruktionen oder wenn die Position wichtig ist
- Beispiel: Wenn das Substantiv in einer festen Wendung vorkommt
